# find-goal-threshold epsilon curves

These are read-only derived visualizations of the immutable formal calibration
root `formal-142ffa7-20260820`. Each task directory contains the plotted PNG
and a manifest that hashes the source config, status, locked threshold when
available, every fit task-stratified score shard, and the PNG itself.

The curves use epsilon on the x-axis and fit-split anchor-group macro TPR/FPR
on the y-axis. PushT and TwoRoom show their locked epsilon. Cube intentionally
has no epsilon line because the pre-registered calibration contract produced
`THRESHOLD_CALIBRATION_NO_FEASIBLE_OPERATING_POINT`.
