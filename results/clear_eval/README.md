# CLEAR-LeWM results

The canonical result set is [v0.5](v0.5/README.md). It contains the complete
four-task, seed-42 CEM matrix for official and project-trained 10-epoch LeWM
policies. Random-policy controls and the project-trained GD solver ablation are
available for PushT and Cube. Each headline number is backed by a structured
`results.txt.json` under `v0.5/raw/`.
